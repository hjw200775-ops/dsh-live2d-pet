# 阶段 A：待机自然化

本次只实现 ROADMAP 的阶段 A，基于 main 的 0.7.3；阶段 B–F 未开始。本次为开发变更，不包含版本发布、模型修改或日常 DSH 安装替换。

| 项目 | 实现 |
|---|---|
| A1 头部漂移 | `noise.mjs` 一维值噪声，独立种子和五次插值；AngleX/Y 低频增量，幅度上限分别为 1.8/1.2 |
| A2 二次眨眼 | 每次眨眼结束后等待 2–6 秒，20% 概率连眨；每下 160 ms，连眨间隔 100 ms；乘到现有眼睛开合值，保留动作中的闭眼 |
| A3 重心转移 | 8–20 秒选择一个对称随机目标，2 秒缓动；AngleZ 和 PositionX 联动，上限分别为 1.4 和 0.012 |
| A4 呼吸浮动 | 瞬时周期在 3.6–4.8 秒缓慢变化，通过积分频率保持相位连续；显式 `period` 参数仍支持固定周期 |

头部漂移与重心转移替换原渲染器的循环剪辑微动叠加；`fidget.mjs` 保留供已有调用者使用。新层只累积允许待机微动时的时间，启停使用 400 ms 包络。拖动、暂停、锁定动作和状态变化会淡出微动。呼吸仍限待机/思考状态；回答时保持原来的眨眼禁用策略。

所有模块位于 `src/runtime/`，不依赖浏览器全局，无新增依赖或构建步骤。模型资源与 Core 不入库、不入包。

## 自动验证

- `node --test test/*.test.mjs`：100 项通过，包括新增 6 项阶段 A 测试。
- 噪声：幅度、格点连续性、固定种子复现、多个短周期的非重复性抽样。有限测试不声称证明数学意义的无周期。
- 眨眼：1000 次间隔分布和连眨比例、两次闭眼时间点、禁用/恢复和长时间跳帧。
- 重心：1000 次目标切换，检查事件间隔、起点连续、2 秒结束值以及参数联动；稀疏采样与逐帧采样一致。
- 呼吸：10 分钟采样，检查瞬时周期、周期变化连续、值域、相邻帧连续性及实际峰间隔。
- 待机层：5 分钟状态切换采样，检查淡入淡出、禁用回零与恢复连续。

## 待实机验收

自动测试不能代替模型观感验证。尚需在装有私有模型和 Core 的桌面环境观察：待机/思考/回答/出错各 10 秒，长时间待机是否偏头，连眨是否自然，以及鼠标慢移、快移、移出、拖动、暂停/恢复。未完成这些实机检查前不宣称发布验收完成。
