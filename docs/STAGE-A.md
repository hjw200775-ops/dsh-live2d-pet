# 阶段 A：待机自然化

本次只实现 ROADMAP 的阶段 A，基于 main 的 0.7.3；阶段 B–F 未开始。本次为开发变更，不包含版本发布、模型修改或日常 DSH 安装替换。

| 项目 | 实现 |
|---|---|
| A1 头部漂移 | `noise.mjs` 一维值噪声，独立种子和五次插值；AngleX/Y 低频增量，幅度上限分别为 1.8/1.2 |
| A2 二次眨眼 | 每次眨眼结束后等待 2–6 秒，20% 概率连眨；每下 160 ms，连眨间隔 100 ms；乘到现有眼睛开合值，保留动作中的闭眼 |
| A3 重心转移 | 8–20 秒选择一个对称随机目标，2 秒缓动；AngleZ 和 PositionX 联动，上限分别为 1.4 和 0.012 |
| A4 呼吸浮动 | 瞬时周期在 3.6–4.8 秒缓慢变化，通过积分频率保持相位连续；显式 `period` 参数仍支持固定周期 |

头部漂移与重心转移替换原渲染器的循环剪辑微动叠加；`fidget.mjs` 保留供已有调用者使用。新层只累积允许待机微动时的时间，启停使用 400 ms 包络。拖动、暂停、锁定动作和状态变化会淡出微动。呼吸仍限待机/思考状态；回答时保持原来的眨眼禁用策略。

渲染器运行时模块位于 `src/runtime/`，不依赖浏览器全局；桌面坐标采样在 `src/desktop/pointer.mjs`。无新增依赖或构建步骤，模型资源与 Core 不入库、不入包。

## 桌面验收修复与跟随设置

- 首次实机长时间运行发现待机增量在 `afterMotionUpdate` 写入后被 `saveParameters` 保存，导致跨帧累积；直接移到 `beforeModelUpdate` 又会错过此模型的控制器到头部参数的物理映射。现通过 `natural-overlay.mjs` 在保存之后、物理之前叠加，使画面生效且基线不受污染。
- 去掉 SDK 对 `ParamBreath` 的固定正弦，只保留本层可变周期呼吸，避免两路驱动相加后顶到上限；保留其余 SDK 通道及动作曲线。
- 用户反馈鼠标跟随间歇中断。增加 Electron 指针坐标兜底，解除待机小动作对跟随的整段屏蔽，头部控制器在物理之前叠加。
- 按用户建议增加右键设置中的「鼠标跟随」开关，以及以头部为中心的圆形识别范围：近 200、中 400（默认）、远 600，单位为屏幕逻辑像素。主进程和 DOM 输入使用同一范围判断；范围外仅发送一次离开事件，不保存范围外指针轨迹。开关和范围会持久化，移出后平滑回正，重新进入恢复。
- 回答/出错、暂停、拖动及手动锁定动作仍抑制跟随；本次验收窗口保持待机供鼠标交互复验。

## 自动验证

- `node --test test/*.test.mjs`：106 项通过（基线 94 项）。
- 噪声：幅度、格点连续性、固定种子复现、多个短周期的非重复性抽样。有限测试不声称证明数学意义的无周期。
- 眨眼：1000 次间隔分布和连眨比例、两次闭眼时间点、禁用/恢复和长时间跳帧。
- 重心：1000 次目标切换，检查事件间隔、起点连续、2 秒结束值以及参数联动；稀疏采样与逐帧采样一致。
- 呼吸：10 分钟采样，检查瞬时周期、周期变化连续、值域、相邻帧连续性及实际峰间隔。
- 待机层：5 分钟状态切换采样，检查淡入淡出、禁用回零与恢复连续。
- 渲染器：真实回调按 Cubism 保存/自然运动/物理/模型更新/恢复的顺序模拟运行 10 分钟，检查基线不累积、物理之前已能读取增量及待机小动作期间仍跟随。
- 指针：覆盖负坐标显示器、边界、移出重入、隐藏、关闭重开、范围调整、窗口移动/缩放，以及设置保存重载。

## 待实机验收

已使用本机现有模型、Core 5.1.0 和 Electron 33.4.11 启动隔离桌面窗口，实际记录画面与模型更新前的参数。首次检测到累积问题；修正物理时序后，三分多钟运行记录中没有头部角度触顶，呼吸保持 0.15–0.85，未出现渲染错误。初轮通过本地 bridge 驱动四种状态；用户反馈跟随异常后，验收结论撤回，修复并增加跟随开关和范围。

当前 PR 仍是草稿，不宣称验收完成。最新带开关/范围的版本仍需复验：鼠标慢移、快移、范围边缘进出、待机小动作期间跟随、关闭/开启、三档范围、重启保留设置、拖动和暂停/恢复。通过后再复查四种状态各 10 秒及长时间待机；确认无阻断问题后才合并。阶段 B 未开始。
